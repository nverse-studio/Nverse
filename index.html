掌控你的 Android 系统.

Nverse Studio 是一款面向 Android 开发者的底层系统调度工具。基于 Shizuku 授权，无需 Root 即可实现深度的系统级操作。

Shizuku 授权与配置

为了保证在无 Root 环境下的系统调用能力，Nverse Studio 强依赖 Shizuku 服务。

注意： 如果 Shizuku 掉线，Nverse 的所有底层功能（包括修改 DPI、冻结应用等）都将失效。

无线调试激活步骤

  • 进入手机系统的“开发者选项”，开启“无线调试”。
  • 进入无线调试页面，点击“使用配对码配对设备”。
  • 在 Shizuku 客户端输入 6 位配对码完成绑定。
  • 返回 Nverse Studio，应用会弹出权限请求，点击“允许”即可。

权限检测代码实现 (Kotlin)

// 检查 Shizuku 绑定状态与授权
fun checkShizukuState(): Boolean {
    return try {
        if (!Shizuku.pingBinder()) {
            Log.w("Nverse", "Shizuku service is offline.")
            return false
        }
        if (Shizuku.checkSelfPermission() == PackageManager.PERMISSION_GRANTED) {
            Log.i("Nverse", "Permission granted. UID: ${Shizuku.getUid()}")
            true
        } else {
            // 如果未授权，向用户发起请求
            Shizuku.requestPermission(0)
            false
        }
    } catch (e: Exception) {
        Log.e("Nverse", "Shizuku check error: ${e.message}")
        false
    }
}

底层 Shell 执行引擎

借助 Kotlin 协程 (Coroutines) 与 Dispatchers.IO，我们实现了极其稳定的异步命令执行流，并支持实时捕获标准输出 (stdout) 与错误输出 (stderr)。

命令执行器封装

suspend fun execShellCmd(cmd: String): String = withContext(Dispatchers.IO) {
    try {
        // 使用 sh -c 执行命令，以支持管道和多条命令拼接
        val process = Runtime.getRuntime().exec(arrayOf("sh", "-c", cmd))
        val reader = BufferedReader(InputStreamReader(process.inputStream))
        val errorReader = BufferedReader(InputStreamReader(process.errorStream))
        val output = StringBuilder()
        var line: String?
        
        // 读取标准输出流
        while (reader.readLine().also { line = it } != null) {
            output.append(line).append("\n")
        }
        // 读取错误输出流
        while (errorReader.readLine().also { line = it } != null) {
            output.append(line).append("\n")
        }
        
        reader.close()
        errorReader.close()
        output.toString().trim().ifEmpty { "执行成功，无返回信息。" }
    } catch (e: Exception) {
        "异常: ${e.message}"
    }
}

Web 混合沙盒 (WebView Bridge)

Nverse Studio 开放了 JavascriptInterface，前端开发者可以在网页中直接调用 Android 底层功能。

前端调用示例 (JavaScript)

// 假设 Java 层注册了名为 'NverseBridge' 的对象
if (window.NverseBridge) {
    // 调用底层的 Shell 执行
    window.NverseBridge.execShell("getprop ro.product.model", function(result) {
        document.getElementById("terminal").innerHTML = `> 设备型号: ${result}`;
    });
}

开发者指南：Java/Kotlin API

Nverse Studio 提供了核心的 AIDL 服务定义，方便开发者在其应用中集成底层的控制能力。

NverseServer 类定义

public class NverseServer extends INverseService.Stub {
    
    /**
     * 执行底层 Shell 命令
     * @param command 要执行的命令，例如 "pm list packages"
     * @return 命令执行后的完整输出日志
     */
    @Override
    public String execCommand(String command) throws RemoteException {
        return ShellUtils.execute(command);
    }

    /**
     * 获取当前服务进程的 UID (通常为 2000，即 ADB 权限)
     */
    @Override
    public int getServerUid() throws RemoteException {
        return android.os.Process.myUid();
    }
}

高频命令字典

以下是 Nverse Studio 内置封装的部分系统级命令，涵盖了极客玩家最常用的调教场景。

应用管理 (pm)

  • pm list packages -3 : 列出所有已安装的第三方应用包名。
  • pm uninstall -k --user 0 <package> : 静默卸载应用（保留数据目录）。
  • pm disable-user --user 0 <package> : 冻结/停用指定应用。
  • pm grant <package> <permission> : 动态授予应用高危权限。

系统设置 (settings)

  • settings put global window_animation_scale 0.5 : 调整系统窗口动画速度。
  • settings get secure android_id : 获取设备 Android ID。

常见问题 (FAQ)

1. 安装时提示“应用未上架”或“风险软件”？

因为 Nverse Studio 涉及底层的权限分发，且未上架官方应用商店，手机自带的安全中心（如华为纯净模式、腾讯手机管家）会自动将其判定为高危应用。请在设置中临时关闭纯净模式/安全拦截，强制完成安装。

2. 为什么显示 Shizuku 已授权，但命令执行失败？

请检查你的 Shizuku 是否因为息屏、重启等原因掉线。部分手机厂商（如 MIUI、ColorOS）会强制杀后台，请将 Shizuku 和 Nverse Studio 都加入电池白名单/后台无限制运行。

3. 应用支持 iOS 吗？

完全不支持。iOS 的沙盒机制异常封闭，严禁任何应用调用底层 Shell 或修改系统参数。本项目为 Android 专属。
